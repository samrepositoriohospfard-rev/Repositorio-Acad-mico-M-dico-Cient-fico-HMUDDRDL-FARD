# Repositorio-Acad-mico-M-dico-Cient-fico-HMUDDRDL-FARD
El Repositorio Académico y Médico Científico del Hospital Universitario Docente tiene como objetivo central consolidar, preservar y difundir la producción intelectual, científica y docente generada en el ámbito hospitalario. Misión  garantizar acceso abierto, y disponibilidad permanente de materiales académicos, clínicos y editoriales.
